# Telegram task manager bot

Пример телеграм-бота на **aiogram** + **SQLite (SQLAlchemy async)** с двумя ролями:
- `admin` может создавать задачи, переключать их статус и смотреть статистику.
- `municipality` видит задачи своего муниципалитета.

## Запуск
1. Создайте файл `.env` и задайте токен:
   ```env
   BOT_TOKEN=ваш_токен
   ```
2. Установите зависимости и запустите бота. При старте автоматически создаются тестовые муниципалитеты:
   - Курчатовский район
   - Калининский район
   - Советский район
   - Металлургический
   - Тракторозаводский

   ```bash
   pip install -r requirements.txt
   python -m bot.main
   ```

## Основные действия в интерфейсе
- `/start` – показывает меню и кнопки выбора роли.
- Кнопка «Выбрать роль» – открывает выбор между «Администратор» и «Муниципалитет» (для муниципалитета можно выбрать название из списка кнопок или ввести вручную).
- Кнопка «➕ Создать задачу» – запускает пошаговое создание задачи (только администратор).
- Кнопки «📋 Задачи»/«📋 Мои задачи» – список задач на ближайшую неделю.\
  Администратор видит кнопку смены статуса, муниципалитет – кнопки статистики, выбора первичного отделения и получения QR-кодов для участников.
